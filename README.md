# Customer Enquiry Routing

## 1  Introduction

The project began as a system design challenge to get hands-on experience on the process of designing an application from scratch, starting from a design problem, understanding its requirements, coming up with a technical design, and then creating an MVP implementation of it.

This application is a Customer Enquiry Routing webapp that allows a user to submit a banking enquiry via a chat interface, and allows human agents to attend to and resolve the enquiry. The main project is for customer enquiries to be assigned to the most suitable human support agent, with language- and skill-matching, as well as capacity-aware routing.

This Frontend webpage repository (TS, Angular) can be found at https://github.com/jbrandonlee/angular-enquiry-routing. There are two routes in this application. Navigate to `/client` for the client-facing enquiry page, or `/agent` for the agent-facing enquiry page. This frontend application is mostly vibe-coded, and the initial requirements document used as a one-shot prompt can be found at PROMPT.md.

The Backend API repository (C#, Dotnet) can be found at https://github.com/jbrandonlee/dotnet-enquiry-routing, along with a detailed breakdown of the overall design process.
